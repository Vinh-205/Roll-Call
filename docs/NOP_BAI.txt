Cách trình diễn Swagger:
1. Mở GET /health, Try it out, Execute: HTTP 200.
2. POST /auth/login: tự nhập tài khoản và mật khẩu của mình.
3. Lấy challengeId và nhập OTP Gmail vào POST /auth/verify.
4. Sao chép token ở response, bấm Authorize, dán token (không thêm Bearer).
5. GET /auth/me: xem hồ sơ và vai trò. GET /courses: xem lớp học.
6. Các mục CRUD sử dụng đúng ID từ danh sách trả về. Chỉ xóa dữ liệu demo.
Không quay rõ mật khẩu, OTP, token hoặc vị trí GPS cá nhân.
